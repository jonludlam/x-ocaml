Drawing from the worker

The same bouncing balls as on the displays page, but drawn by the cell's code itself. X_ocaml_lib.Canvas.display puts a canvas on the page, which hands its drawing surface to the worker as an OffscreenCanvas; X_ocaml_lib.animate calls the cell's code at each of the worker's animation frames, and what it draws shows on the page. No frame is sent as a message: the page's thread does nothing but show them. Click the box to add a ball.

type ball = { mutable x : float; mutable y : float; mutable vx : float; mutable vy : float; r : float; colour : string } let width = 640. and height = 320. let colours = [| "#f47c34"; "#5fd08f"; "#6b9bf0"; "#e0a847"; "#f06a6a"; "#b48cf0" |] let balls = ref [] let add x y = balls := { x; y; vx = Random.float 8. -. 4.; vy = -. Random.float 4.; r = 6. +. Random.float 12.; colour = colours.(Random.int 6) } :: !balls let () = for _ = 1 to 12 do add (Random.float width) (Random.float (height /. 2.)) done let step () = List.iter (fun b -> b.vy <- b.vy +. 0.3; b.x <- b.x +. b.vx; b.y <- b.y +. b.vy; if b.y +. b.r > height then begin b.y <- height -. b.r; b.vy <- -. b.vy *. 0.93 end; if b.x -. b.r < 0. || b.x +. b.r > width then begin b.x <- Float.max b.r (Float.min (width -. b.r) b.x); b.vx <- -. b.vx end) !balls let draw c = let open X_ocaml_lib.Canvas in set_fill_style c "#141925"; fill_rect c 0. 0. (float (width c)) (float (height c)); List.iter (fun b -> begin_path c; arc c b.x b.y b.r 0. (2. *. Float.pi); set_fill_style c b.colour; fill c) !balls let running = ref true let () = ignore (X_ocaml_lib.Canvas.display ~width:640 ~height:320 ~on_click:(fun x y -> add x y) (fun c -> let _stop = X_ocaml_lib.animate (fun _ -> if !running then step (); draw c) in ())) let () = let toggle = X_ocaml_lib.callback (fun _ -> running := not !running) in let shake = X_ocaml_lib.callback (fun _ -> List.iter (fun b -> b.vy <- b.vy -. 8. -. Random.float 6.; b.vx <- b.vx +. Random.float 6. -. 3.) !balls) in ignore (X_ocaml_lib.html (Printf.sprintf {|<button data-callback="%d">pause or play</button> <button data-callback="%d">shake</button> click the box to add a ball|} toggle shake))

Run the cell again and the old canvas goes, with the loop that drew it: animate belongs to the cell that called it. A long computation in another cell holds up the frames, as the worker is busy with it.
