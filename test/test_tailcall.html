A call marked [@tailcall] that is not a tail call draws warning 51 (wrong-tailcall-expectation), as in the native toplevel. The page runs on the plain worker, or on the effects worker with ?worker=effects, where the compiler's pass is the same but the code it makes is not.

A call under an addition is not a tail call

let rec nsum n = if n = 0 then 0 else n + (nsum [@tailcall]) (n - 1)

A call in tail position draws no warning

let rec summing n t = if n = 0 then t else (summing [@tailcall]) (n - 1) (n + t)

A call under try ... with is not a tail call

let rec f n = try if n = 0 then 0 else (f [@tailcall]) (n - 1) with Not_found -> 0

Mutual recursion, in the branches of a match

let rec even n = match n with 0 -> true | n -> (odd [@tailcall]) (n - 1) and odd n = match n with 0 -> false | n -> (even [@tailcall]) (n - 1)

As an error, with [@@@ocaml.warnerror "+51"]

The warning comes from the pass after typing, and the toplevel defines the function all the same, as the native toplevel does: a checker must read the diagnostics, not count on the phrase failing.

[@@@ocaml.warnerror "+51"] let rec nsum2 n = if n = 0 then 0 else n + (nsum2 [@tailcall]) (n - 1)
