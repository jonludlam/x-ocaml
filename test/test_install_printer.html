A printer installed with #install_printer can give the page HTML with X_ocaml_lib.output_html, as well as printing text: the HTML shows under the phrase whose value it printed.

type dot = Dot of string let pp ppf (Dot colour) = X_ocaml_lib.output_html (Printf.sprintf "<span class='dot' style='color:%s'>&#x25CF;</span>" colour); Format.fprintf ppf "a %s dot" colour #install_printer pp let red = Dot "red" let answer = 42 let blue = Dot "blue"
