Cells with the same group attribute are one program: a module, say, shown a few lines at a time with prose between. They run together, in page order, when the last of them runs.

A module in four cells, then a cell that uses it

module M = struct

Some prose about the first definition.

let x = 20

And the next.

let y = x * 2 let z = y + 2 end let g1 = M.z

An error goes to the member it is in

module B = struct let ok = 1 let broken = "a" + 1 let fine = 2 end

A member changes, and its Run button runs the group (uses G1's cells)

Members keep their indentation, and a blank hidden member is a line

module W = struct let a = 1 let b = "a" ^ 1 end

A hidden member: its code runs, and line numbers count it

module H = struct let secret = 7 let other = 8 let shown = secret * 6 end let g3 = H.shown

An error about hidden code goes to a visible member

module S : sig val x_ : int end = struct let x = 1 end

An error about a range of lines goes to the member with its last line

module T : sig val x_ : int end = struct let x = 1 end

With another cell between members, messages number lines as the gutters do

module I = struct let one = 1 let between = 1 let and_more = 2 let lines = 3 let two = "two" + 1 end
