A cell's mode attribute says how it treats its code: interactive by default, exercise, test, or hidden.

A hidden cell shows nothing, and the next cell sees its definitions

let secret = 42 let t1 = secret + 1

Interactive, asked for and by default

let t2 = 1 + 2 let t2_default = 99

An exercise and the test that names it

let double x = x * 2 assert (double 5 = 10)

An exercise with merlin turned off

let t4 : int = "not merlin"

A failing test, linked by position to the exercise before it

It fails with failwith: a failed assert reports a JavaScript error.

let fact n = n if fact 3 <> 6 then failwith "fact 3 should be 6"

A test that does not typecheck

let six = 6 let _ : string = six

The page restyles T2's first cell through the --xo-* variables
