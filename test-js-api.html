x-ocaml JavaScript API Demo

Available API:
  • xOcaml.setHighlight(id, spec) - Set highlighting on a cell (id can be string or number)
  • xOcaml.clearHighlight(id) - Clear all highlighting from a cell
  • xOcaml.getCellId(index) - Get numeric cell ID by index (0-based)
  • xOcaml.getCellCount() - Get total number of cells

Control "factorial" Cell:

Example 1: Factorial Function

let rec factorial n = if n <= 1 then 1 else n * factorial (n - 1)

Control "list-ops" Cell:

Example 2: List Operations

let numbers = [1; 2; 3; 4; 5] let doubled = List.map (fun x -> x * 2) numbers let sum = List.fold_left (+) 0 numbers

Control "pattern-match" Cell:

Example 3: Pattern Matching

let describe_list = function | [] -> "empty" | [x] -> "single element" | x :: xs -> "multiple elements"

Try it in the console:

// Using string IDs (NEW!)
xOcaml.setHighlight("factorial", "2");
xOcaml.setHighlight("list-ops", "2:8-16");
xOcaml.clearHighlight("pattern-match");

// Or using numeric IDs (still works)
let cellId = xOcaml.getCellId(0);
xOcaml.setHighlight(cellId, "2");

// Multiple highlights
xOcaml.setHighlight("factorial", "1-2,4:0-5");

// Get cell count
console.log("Total cells:", xOcaml.getCellCount());
