WebGL Tutorial 1: Getting Started with WebGL

This tutorial introduces WebGL basics. We'll initialize a WebGL context and clear the canvas to a solid color. This is the foundation for all WebGL applications.

Example: Clear to Black

The simplest WebGL program: get a WebGL context and clear the canvas to black.

open Js_of_ocaml (* Create a canvas widget *) let canvas_id = X_ocaml_lib.X_canvas.create ~width:640 ~height:480;; (* Initialize WebGL when canvas is ready *) X_ocaml_lib.X_canvas.when_ready canvas_id (fun canvas -> (* Get OffscreenCanvas as a generic JavaScript object *) let offscreen = X_ocaml_lib.X_canvas.get_offscreen canvas in (* Create context attributes with alpha: false for opaque background *) let attrs = object%js val alpha = Js._false val antialias = Js._true val depth = Js._true val failIfMajorPerformanceCaveat = Js._false val preferLowPowerToHighPerformance = Js._false val premultipliedAlpha = Js._true val preserveDrawingBuffer = Js._false val stencil = Js._false end in (* Get WebGL context from OffscreenCanvas using Jv.call *) let gl_jv = Jv.call offscreen "getContext" [| Jv.of_string "webgl"; Jv.repr attrs |] in if Jv.is_null gl_jv then print_endline "Unable to initialize WebGL. Your browser may not support it." else begin (* Cast to WebGL rendering context *) let gl : WebGL.renderingContext Js.t = Obj.magic gl_jv in print_endline "WebGL context obtained successfully"; (* Set clear color to black, fully opaque *) gl##clearColor (Js.number_of_float 0.0) (Js.number_of_float 0.0) (Js.number_of_float 0.0) (Js.number_of_float 1.0); print_endline "clearColor called with (0, 0, 0, 1)"; (* Clear the color buffer *) gl##clear gl##._COLOR_BUFFER_BIT_; print_endline "gl.clear() called"; (* Check for WebGL errors *) let error = gl##getError in if error = gl##._NO_ERROR_ then print_endline "No WebGL errors - rendering complete!" else Printf.printf "WebGL error: %d\n" error end )

Example: Clear to Blue

Same as above, but clearing to a nice blue color instead of black.

open Js_of_ocaml (* Create a canvas widget *) let canvas_id = X_ocaml_lib.X_canvas.create ~width:640 ~height:480;; (* Initialize WebGL when canvas is ready *) X_ocaml_lib.X_canvas.when_ready canvas_id (fun canvas -> let offscreen = X_ocaml_lib.X_canvas.get_offscreen canvas in (* Create context attributes with alpha: false *) let attrs = object%js val alpha = Js._false val antialias = Js._true val depth = Js._true val failIfMajorPerformanceCaveat = Js._false val preferLowPowerToHighPerformance = Js._false val premultipliedAlpha = Js._true val preserveDrawingBuffer = Js._false val stencil = Js._false end in let gl_jv = Jv.call offscreen "getContext" [| Jv.of_string "webgl"; Jv.repr attrs |] in if Jv.is_null gl_jv then print_endline "Unable to initialize WebGL." else begin let gl : WebGL.renderingContext Js.t = Obj.magic gl_jv in print_endline "WebGL context obtained successfully"; (* Set clear color to blue: RGB(0.2, 0.4, 0.8) *) gl##clearColor (Js.number_of_float 0.2) (Js.number_of_float 0.4) (Js.number_of_float 0.8) (Js.number_of_float 1.0); print_endline "clearColor called with (0.2, 0.4, 0.8, 1)"; gl##clear gl##._COLOR_BUFFER_BIT_; print_endline "gl.clear() called"; (* Check for WebGL errors *) let error = gl##getError in if error = gl##._NO_ERROR_ then print_endline "No WebGL errors - rendering complete!" else Printf.printf "WebGL error: %d\n" error end )
