Running and stopping

While a cell runs, its button turns into a spinning stop button. So does the button of any cell waiting for it.

let rec fib n = if n < 2 then n else fib (n - 1) + fib (n - 2)

This takes a few seconds; the spinner shows it is working.

let slow = fib 32

Quick, and it runs the slow cell above it first if that has not run.

let quick = fib 20

This never ends. Run it, then press the button again to stop it. Stopping is drastic: OCaml code cannot be interrupted, so x-ocaml starts a fresh toplevel, which knows nothing of what ran before, and every cell is cleared. Run the quick cell above again afterwards: it runs the cells above it first, on the new toplevel. (A cell below this one could never run: it would run this one first.)

let rec forever n = forever (n + 1) in forever 0

Edit a cell while it runs and its result is thrown away when it comes: it would be for code that is no longer there.
