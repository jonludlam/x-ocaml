Bach's invention, as a program

The Invention No. 1 in C major, BWV 772, rebuilt from its two motifs.

Although I usually prefer the late romantics when it comes to music, I've always had a bit of a soft spot for Bach. His music manages to be very beautiful despite, or perhaps because of, being very mathematical. We're going to show off some of the mathematical bits in this doc by recreating one of Bach's two part inventions programmatically.

So here we are, we're going to be recreating BWV 772 using OCaml code and rendered, visually and aurally, by a mix of OCaml and javascript

The notes are coloured by where they come from: ■ the run ■ the run, upside down ■ the leap ■ the left hand's quavers ■ the quavers, upside down ■ thirds ■ held notes ■ written out

Notes

The important choice is how to write a pitch. Bach moves his figures up and down the scale. The run from C, C–D–E–F, becomes D–E–F–G when it starts on D, which is a different pattern of tones and semitones but the same figure. So a pitch here is a step of the scale: a letter name in an octave, with no sharp or flat. The sharps and flats come from the key the music is in, or from a patch on a single note.

(* A pitch is a step of the scale: a letter name in an octave, counted up from C0, so that middle C, C4, is 28. Sharps and flats are left to the key, or to a patch on the note. *) type ornament = Mordent | Prall (* inverted mordent! *) (* Where a note came from, to colour it by in the score. *) type origin = A | A_inv | B | Counter | Counter_inv | Thirds | Held | Free type note = { steps : int list; (* none for a rest, several for a chord *) alt : int option; (* semitones up, or None to leave it to the key *) dur : int; (* in demisemiquavers *) orn : ornament option; origin : origin; } type line = note list let demisemiquaver = 1 and semiquaver = 2 and quaver = 4 let crotchet = 8 and minim = 16 and semibreve = 32 let length l = List.fold_left (fun n x -> n + x.dur) 0 l let letters = "cdefgab" (* [p "g4"] is the G above middle C. *) let p s = match String.index_opt letters s.[0] with | Some i when String.length s = 2 -> (7 * (Char.code s.[1] - Char.code '0')) + i | _ -> invalid_arg ("p: " ^ s) let note ?(origin = Free) dur step = { steps = [ step ]; alt = None; dur; orn = None; origin } let rest dur = { steps = []; alt = None; dur; orn = None; origin = Free } let chord dur names = { (rest dur) with steps = List.map p names } (* A line prints as its size. *) let pp_line ppf l = let n = List.length (List.filter (fun x -> x.steps <> []) l) in Format.fprintf ppf "<%d notes, %g bars>" n (float (length l) /. float semibreve);; #install_printer pp_line

A key says which letter names it sharpens or flattens. The piece goes through G major, D minor and A minor. In a minor key, a line going up sharpens more notes than one coming down, so those keys come in two forms.

(* A key says how it alters each letter name. *) type key = { name : string; alts : (char * int) list } let c_major = { name = "C major"; alts = [] } let g_major = { name = "G major"; alts = [ ('f', 1) ] } let f_major = { name = "F major"; alts = [ ('b', -1) ] } let d_minor = { name = "D minor"; alts = [ ('b', -1); ('c', 1) ] } let a_minor = { name = "A minor"; alts = [ ('g', 1) ] } (* Minor keys going up raise the sixth as well as the seventh, and Bach's D minor, going up, takes the B natural. *) let d_minor_rising = { name = "D minor, rising"; alts = [ ('c', 1) ] } let a_minor_rising = { name = "A minor, rising"; alts = [ ('f', 1); ('g', 1) ] } let alt_in key step = Option.value ~default:0 (List.assoc_opt letters.[step mod 7] key.alts)

The cell folded away below holds the plumbing. It turns the lines into events (times, MIDI notes and lengths), writes them as ABC notation, and hands that to a small element that draws it with abcjs. It also reads written-out music, in a notation borrowed from Humdrum, such as notes "8 a4 d4 8. c5!p 16 d5":

8, 16, 4., 2+16
a length, which lasts until the next: a quaver, a semiquaver, a dotted crotchet, a minim tied to a semiquaver;
c4, f#3, bb4, gn3
a pitch, with its octave, and a sharp, flat or natural when the key would not give it;
r
a rest;
c5!m, c5!p
a note with a mordent, down to the next note of the scale and back, or a prall, up to it and back.

The ornaments are played written out, with the next note in the scale of the key the music is in. Left to itself, abcjs plays every ornament a whole tone away, but the prall in bar 1, on B, goes up a semitone to C.

The two motifs

Here is the whole of the first bar in the right hand: a semiquaver rest, then the run, seven semiquavers up four notes and back, then the leap, four quavers up a fifth, an octave, down a step and back up. Both are written as steps above the note the run starts on.

(* A figure: its lengths and its steps above the note it starts from. *) let shape origin dur offsets start = List.map (fun k -> note ~origin dur (start + k)) offsets (* The run: seven semiquavers, up four notes and back. *) let a start = shape A semiquaver [ 0; 1; 2; 3; 1; 2; 0 ] start (* The leap: four quavers, measured from the same note as the run. *) let b start = shape B quaver [ 4; 7; 6; 7 ] start (* Each run starts on the second semiquaver of its half bar. The first is a rest, or a note joining the run to what went before. *) let r16 = [ rest semiquaver ] let pickup step = [ note ~origin:A semiquaver step ] let ( ++ ) = ( @ ) let subject start = r16 ++ a start ++ b start let () = show [ subject (p "c4") ]

Moving them

Nearly everything Bach does to the motifs is one of a few operations: move it up or down the scale, turn it upside down, take part of it, and now and then alter one note. Every alteration is a patch, done where it is needed, so it is plain what is not systematic.

let map_steps f l = List.map (fun x -> { x with steps = List.map f x.steps; alt = None }) l (* Up [k] steps of the scale. *) let transpose k l = map_steps (fun s -> s + k) l let inverse = function | A -> A_inv | A_inv -> A | Counter -> Counter_inv | Counter_inv -> Counter | o -> o (* Upside down, about its first note. *) let invert l = let axis = match List.find_opt (fun x -> x.steps <> []) l with | Some { steps = s :: _; _ } -> s | _ -> invalid_arg "invert: only rests" in List.map (fun x -> { x with origin = inverse x.origin }) (map_steps (fun s -> (2 * axis) - s) l) let take n l = List.filteri (fun i _ -> i < n) l let tagged origin l = List.map (fun x -> { x with origin }) l (* Patches, on the [i]th note of a line, counting from 0. *) let patch i f l = List.mapi (fun j x -> if i = j then f x else x) l let sharp i = patch i (fun x -> { x with alt = Some 1 }) let natural i = patch i (fun x -> { x with alt = Some 0 }) let ornament i o = patch i (fun x -> { x with orn = Some o }) let replace i step = patch i (fun x -> { x with steps = [ step ]; alt = None }) let a_inv start = invert (a start)

Moved up the scale a step at a time, the run keeps its shape but changes its tones and semitones. Turned upside down, it falls and comes back up.

(* The run from each note of the scale, and upside down. *) let () = show [ List.concat_map (fun k -> a (p "c4" + k)) [ 0; 1; 2; 3 ] ] let () = show [ List.concat_map (fun k -> a_inv (p "c5" - k)) [ 0; 1; 2; 3 ] ]

Figures

A few figures made from the motifs come back more than once. The most important is descent: the inverted run, falling through a sequence of thirds. It first appears in bar 3, over quavers in the left hand that go on to have a life of their own.

(* A note held over a half bar, into the next. *) let held step = [ note ~origin:Held (minim + semiquaver) step ] (* The inverted run, falling in thirds, each picked up from the step above, the first from further off. *) let descent start n = List.concat (List.init n (fun i -> let s = start - (2 * i) in pickup (if i = 0 then s - 3 else s + 1) ++ a_inv s)) (* The end of the inverted run, as a figure of its own. *) let thirds start = shape Thirds semiquaver [ 0; 2; 1; 3 ] start (* A hand's first note of a bar, then silence until its run. *) let echo step figure = [ note quaver step; rest quaver; rest crotchet ] ++ r16 ++ figure (* The left hand's quavers under the first descent. *) let counter = tagged Counter (notes "8 c4 b3 c4 d4 e4 g3 a3 b3 | c4 e3 f3 g3 a3 b3 4+16 c4") (* As in bars 3 and 4: in C, and in G from the second bar. *) let () = show ~keys:[ ((1, 0), c_major); ((2, 0), g_major) ] [ descent (p "a5") 4; counter ]

The key plan

The piece moves to G major by bar 7 and to A minor by bar 14, and comes home through F major. The hands change key at different times, so each has its own plan.

(* The keys each hand is in, from which bar and semiquaver. *) let right_keys = [ ((1, 0), c_major); ((4, 0), g_major); ((9, 0), c_major); ((11, 0), d_minor_rising); ((12, 0), a_minor_rising); ((14, 0), a_minor); ((15, 0), c_major); ((21, 0), f_major); ((21, 8), c_major) ] let left_keys = [ ((1, 0), c_major); ((3, 0), g_major); ((9, 0), c_major); ((11, 0), d_minor); ((12, 0), a_minor); ((13, 0), a_minor_rising); ((14, 0), a_minor); ((15, 0), c_major); ((18, 0), f_major); ((20, 0), c_major) ]

The invention, a passage at a time

(* The invention is a list of passages, each the two hands over the same stretch, though a note held over the join may be on either side. *) let passages : (string * (line * line)) list ref = ref [] let starts name = let rec go r l = function | [] -> (r, l) | (n, _) :: _ when n = name -> (r, l) | (_, (right, left)) :: ps -> go (r + length right) (l + length left) ps in go 0 0 !passages (* [passage name music] adds it, or puts it in the place of the passage of that name, and draws it where it falls in the piece. *) let passage name music = passages := (if List.mem_assoc name !passages then List.map (fun (n, m) -> if n = name then (n, music) else (n, m)) !passages else !passages @ [ (name, music) ]); let r, l = starts name in let right, left = music in draw ~clefs:[ "treble"; "bass" ] [ perform ~keys:right_keys ~from:r right; perform ~keys:left_keys ~from:l left ]

Bars 1 and 2. The right hand plays the subject. The left answers with the run an octave lower, then drops from G to low G while the right hand plays the subject again, on G. There, the note before the run is a D rather than a rest.

let opening = (subject (p "c4") |> ornament 10 Prall) ++ (pickup (p "d5") ++ a (p "g4") ++ b (p "g4") |> ornament 10 Prall) let () = passage "exposition" ( opening, [ rest minim ] ++ r16 ++ a (p "c3") ++ notes "8 g3 g2 4 r" ++ r16 ++ a (p "g3") )

Bars 3 to 5. The inverted run falls through four thirds in the right hand, over the left hand's quavers, and the passage ends on a half close in G.

let descending = (descent (p "a5") 4 ++ notes "8 a4 d4 8. c5!m 16 d5", counter ++ a (p "d3")) let () = passage "first descent" descending

Bars 5 and 6. One more inverted run, and a cadence in G made from its last four notes.

let () = passage "to G" ( pickup (p "b4") ++ a_inv (p "a4") ++ thirds (p "g4") ++ thirds (p "b4") ++ notes "16 d5 32 b4 c5 16 d5 g5 8 b4!p 16 a4 g4", notes "8 g3 b2 c3 d3 | e3 f3 g3 e3 8. b2 16 c3 8 d3 d2" )

Bars 7 and 8. The opening again in G, with the hands swapped. The left hand plays what the right hand played in bars 1 and 2, a twelfth lower, note for note.

let () = passage "the exposition in G, hands swapped" ( echo (p "g4") (a (p "g4")) ++ (echo (p "f4") (a (p "a4")) |> ornament 0 Prall), (* the right hand's first two bars, a twelfth lower *) transpose (-10) opening |> List.map (fun x -> { x with orn = None }) )

Bars 9 and 10. Both hands have the run upside down. Bar 10 is bar 9 one step higher, apart from one note. A C sharp points the way to D minor.

let () = passage "upside down" (let bar_9 = pickup (p "g3") ++ a_inv (p "g4") ++ notes "8 f4 e4 f4 d4" in ( echo (p "b4") (a_inv (p "d5")) ++ echo (p "c5") (a_inv (p "e5") |> sharp 5), bar_9 ++ (transpose 1 bar_9 |> replace 0 (p "e4")) ))

Bars 11 to 13. Bars 3 to 5 again, with the hands swapped. The left hand's quavers go up a ninth into the right hand, and the right hand's descent goes down a seventh into the left, in D minor and then A minor. This is invertible counterpoint: two lines that make good harmony either way up.

let () = passage "the descent again, hands swapped" (let right, left = descending in ( transpose 8 left ++ notes "16 e5 d5 c5 e5 d5 c5 b4 d5", transpose (-6) right ++ (pickup (p "c4") ++ a_inv (p "b3") |> natural 3) ))

Bar 14. The cadence in A minor. The left hand has the thirds of bar 6, but the right hand's line is new, and written out.

The whole invention

Every passage, one after the other. The notes, their times, lengths and ornaments are the same as in David Huron's Humdrum edition of the piece, all 455 of them, with its ornaments read as the Bach-Gesellschaft edition prints them.

(* The two hands of the whole piece, performed. *) let invention () = let music = List.map snd !passages in let right = List.concat_map fst music and left = List.concat_map snd music in if length right <> length left then failwith (Printf.sprintf "the right hand lasts %d demisemiquavers, the left %d" (length right) (length left)); (perform ~keys:right_keys right, perform ~keys:left_keys left) let () = let right, left = invention () in draw ~title:"Invention No. 1" ~bars_per_line:4 [ right; left ]

What abcjs draws and plays is ABC text, which says a note's sharp or flat only when the key and the bar so far do not. Read back, it should give the program's notes exactly, and here it does.

(* The score as written for abcjs has the program's notes, all of them. *) let () = let right, left = invention () in let text, _, _ = abc ~bars_per_line:4 [ right; left ] in let heard = sounding right @ sounding left and read = List.concat (read_abc text) in if heard <> read then failwith "the score as written is not the program's" else Printf.printf "The score as written has the program's %d notes.\n" (List.length read)

How much of it comes from the motifs:

let names = [ (A, "the run"); (A_inv, "the run, upside down"); (B, "the leap"); (Counter, "the quavers"); (Counter_inv, "the quavers, upside down"); (Thirds, "thirds"); (Held, "held notes"); (Free, "written out") ] let counts = let right, left = invention () in let sounding = List.filter (fun e -> e.midi <> []) (right @ left) in List.map (fun (o, name) -> (name, List.length (List.filter (fun e -> e.from = o) sounding))) names (* As a bar of colours, one for each origin, as wide as its count. *) let () = let total = List.fold_left (fun n (_, c) -> n + c) 0 counts in let cell (o, _) (name, c) = Printf.sprintf {|<div title="%s: %d" style="flex:%d;background:%s;color:#fff;padding:0.3rem 0.4rem;overflow:hidden;white-space:nowrap;text-overflow:ellipsis">%d</div>|} name c c (colour o) c in let key (o, _) (name, c) = Printf.sprintf {|<span style="margin-right:1rem;white-space:nowrap"><b style="color:%s">■</b> %s, %d</span>|} (colour o) name c in ignore (X_ocaml_lib.html (Printf.sprintf {|<div style="display:flex;border-radius:4px;overflow:hidden;font-size:0.85rem">%s</div> <div style="margin-top:0.5rem;font-size:0.9rem">%s</div> <p style="margin:0.5rem 0 0">%d notes in all.</p>|} (String.concat "" (List.map2 cell names counts)) (String.concat " " (List.map2 key names counts)) total))

So Bach's two ideas, handled in a few ways, give four notes in every five. Three in every five are the run itself, one way up or the other. The notes written out are mostly cadences, the stock formulas that close a phrase, with the line of bar 14 and the last bars.

This counting is a little generous to the motifs. The note before each run, a rest in bar 1, is sometimes a note chosen to lead into the run, and it is counted as part of it. And a note with a patch, a sharp or a natural or an ornament, still counts as part of the figure it was patched in.
