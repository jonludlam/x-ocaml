Predict the next step

Watching a computation teaches little; predicting it first teaches more. Each cell below records the states of a computation with Focs_check.Steps, and shows them with <x-stepper>: press ▶ and, for the first few steps and the last, choose what comes next before it is shown. The wrong choices are mistakes people make, and choosing one says what it gets wrong.

Lists are drawn as chains of cells, and a cell shared by two lists is drawn once, with two arrows to it: the sharing is the program's own, found by physical equality. From a script, step(), back() and reset() drive it, and mode = "lecture" stops it asking, as a slide would.

Reversing a list with an accumulator

open Focs_check let show l = "[" ^ String.concat "; " (List.map string_of_int l) ^ "]" (* The code the reader sees; [line xs] is the line that runs next. *) let rev_code = {|let rec go xs acc = match xs with | [] -> acc | x :: rest -> go rest (x :: acc) let rev l = go l []|} let line xs = if xs = [] then 3 else 4 let rev_steps l = let t = Steps.create () in let st label xs acc = Steps.state ~label ~line:(line xs) ~highlight:[ Steps.list string_of_int acc ] [ ("l", Steps.list string_of_int l); ("xs", Steps.list string_of_int xs); ("acc", Steps.list string_of_int acc) ] in let go_label xs acc = Printf.sprintf "go %s %s" (show xs) (show acc) in Steps.add t (st ("rev " ^ show l ^ " = " ^ go_label l []) l []); let rec go xs acc = match xs with | [] -> acc | x :: rest -> let acc' = x :: acc in let wrong = [ ( Printf.sprintf "x :: acc puts %d in front of the accumulator, not after it." x, acc @ [ x ] ); ("Nothing is lost: the head of the list moves onto the accumulator.", acc); ("The accumulator is extended, not replaced: it keeps what it had.", [ x ]) ] |> List.filter (fun (_, a) -> a <> acc') |> List.sort_uniq (fun (_, a) (_, b) -> compare a b) |> List.map (fun (why, a) -> (why, st (go_label rest a) rest a)) in Steps.add t ~choices:wrong (st (go_label rest acc') rest acc'); go rest acc' in let r = go l [] in Steps.add t ~choices:[ ("go returns the accumulator, which holds the elements in the \ reverse of the order they were met.", Steps.state ~label:("= " ^ show l) [ ("result", Steps.list string_of_int l) ]) ] (Steps.state ~label:("= " ^ show r) [ ("result", Steps.list string_of_int r) ]); t let () = Steps.show ~title:"rev [1; 2; 3; 4]" ~code:rev_code (rev_steps [ 1; 2; 3; 4 ])

Traversing a tree: preorder, inorder, postorder

The node being visited is marked, and here points to it. The wrong choices are the node the other two orders would visit.

open Focs_check type 'a tree = Lf | Br of 'a * 'a tree * 'a tree let view = function Lf -> None | Br (v, l, r) -> Some (v, [ l; r ]) let rec preorder = function Lf -> [] | Br (v, l, r) -> (v :: preorder l) @ preorder r let rec inorder = function Lf -> [] | Br (v, l, r) -> inorder l @ (v :: inorder r) let rec postorder = function Lf -> [] | Br (v, l, r) -> postorder l @ postorder r @ [ v ] let rec find v = function | Lf -> None | Br (w, l, r) as t -> if v = w then Some t else (match find v l with Some t -> Some t | None -> find v r) let code_of = function | "preorder" -> "let rec preorder = function\n | Lf -> []\n | Br (v, l, r) -> (v :: preorder l) @ preorder r" | "inorder" -> "let rec inorder = function\n | Lf -> []\n | Br (v, l, r) -> inorder l @ (v :: inorder r)" | _ -> "let rec postorder = function\n | Lf -> []\n | Br (v, l, r) -> postorder l @ postorder r @ [ v ]" let orders = [ ("preorder", preorder, "That is preorder: a node comes before its subtrees."); ("inorder", inorder, "That is inorder: the left subtree comes before the node."); ("postorder", postorder, "That is postorder: both subtrees come before the node.") ] let traversal_steps name t = let _, order, _ = List.find (fun (n, _, _) -> n = name) orders in let s = Steps.create () in let tree = Steps.tree string_of_int view t in let st label here visited = let here_v = Steps.tree string_of_int view here in Steps.state ~label ~line:3 ~highlight:[ here_v ] [ ("t", tree); ("here", here_v); ("visited", Steps.list string_of_int visited) ] in Steps.add s (Steps.state ~label:(name ^ " t") [ ("t", tree); ("visited", Steps.list string_of_int []) ]); let seq = order t in List.iteri (fun i v -> let before = List.filteri (fun j _ -> j < i) seq in let here x = Option.get (find x t) in let wrong = List.filter_map (fun (n, o, why) -> match List.nth_opt (o t) i with | Some w when n <> name && w <> v && not (List.mem w before) -> Some (w, why) | _ -> None) orders |> List.sort_uniq (fun (a, _) (b, _) -> compare a b) |> List.map (fun (w, why) -> (why, st (Printf.sprintf "visit %d" w) (here w) (before @ [ w ]))) in Steps.add s ~choices:wrong (st (Printf.sprintf "visit %d" v) (here v) (before @ [ v ]))) seq; s let t = Br (4, Br (2, Br (1, Lf, Lf), Br (3, Lf, Lf)), Br (6, Br (5, Lf, Lf), Lf)) let () = List.iter (fun (name, _, _) -> Steps.show ~title:name ~code:(code_of name) ~ask:6 (traversal_steps name t)) orders
