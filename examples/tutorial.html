let check name ok = if not ok then failwith ("check failed: " ^ name)

Building lists

A list is either empty, [], or an element in front of a list, x :: rest.

let numbers = 1 :: 2 :: 3 :: [] let same = [1; 2; 3] let equal = numbers = same

Exercise: the length of a list

Write length, which counts the elements of a list. Your version is kept in this browser, so you can reload the page without losing it; Reset brings back the start.

let rec length l = match l with | [] -> 0 | _ :: rest -> 1 + length rest

The tests below run each time the exercise does. Unfold them to see what they check.

check "empty" (length [] = 0); check "three" (length [1; 2; 3] = 3)

Exercise: the sum of a list

This one is yours to finish: at the moment it fails, and so do its tests.

let rec sum l = failwith "write sum" check "empty" (sum [] = 0); check "three" (sum [1; 2; 3] = 6)

Tests that name their exercise

A test normally checks the nearest exercise above it. With data-for it names one by its data-id, so a page can gather its tests at the end.

let rev l = List.fold_left (fun acc x -> x :: acc) [] l let unrelated = "tests need not follow their exercise" check "rev" (rev [1; 2; 3] = [3; 2; 1]); check "twice" (rev (rev [1; 2]) = [1; 2])

A test's verdict is read from what it prints: an exception is a failure (✗), any other error, such as a type error, a problem with the test itself (!).
