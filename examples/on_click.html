Nothing runs until asked

This page's script says run-on="click", so its cells wait to be run. Its element is called <ocaml-cell> rather than <x-ocaml>, chosen with elt-name.

A cell can ask to run on load for itself, but only if every cell before it runs on load too: running a cell runs the cells above it first, and those are waiting to be asked. So this one, at the top of the page's cells, has run already:

let opened = "ran when the page opened" let greeting = "hello"

Running this one runs the one above first.

let loud = String.uppercase_ascii greeting

Asking to run on load here, after cells that wait, has no effect:

let late = "runs only when clicked, or when a cell below it is"
