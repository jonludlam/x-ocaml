Celtic knots

Drawn by following a thread around a graph.

The interlace in the Book of Kells and on the high crosses looks as if it must have been drawn one careful stroke at a time. It was built from a method, though, and the method is simple enough to put into a program. Start with a regular plait, where every strand goes over, then under, then over. Then break it here and there, turning strands back where they would have crossed. J. Romilly Allen described knotwork this way in 1904, and George Bain's Celtic Art: The Methods of Construction (1951) taught a generation to draw it.

This page takes a slightly more general view, following Christian Mercat. Every Celtic knot is drawn over a graph: dots, with lines between them. The threads cross at the middle of every line and wrap round the dots. A plait is the knot of a square grid, and breaks are changes to single edges. The cells below are OCaml, running in your browser. They build the graph, follow the threads and draw the picture, and you can change any of them and run it again.

The graph

A graph here is a set of points in the plane, joined by straight edges. At the middle of each edge, one of three things happens.

Cross
the two threads that meet there cross over each other;
Along
there is a wall along the edge, and the threads turn back to stay on their own side of it;
Across
there is a wall across the edge, and the threads turn back to stay at their own end of it.
(* A graph drawn in the plane: points, and straight edges between them. The threads of the knot cross at the middle of every edge. *) type graph = { pos : (float * float) array; edges : (int * int) array } (* At each edge the threads cross, or turn back before it: [Along] puts a wall along the edge, [Across] puts one across it. *) type junction = Cross | Along | Across let every kind g = Array.make (Array.length g.edges) kind (* Points in the plane are pairs of floats. *) let ( +: ) (a, b) (c, d) = (a +. c, b +. d) let ( -: ) (a, b) (c, d) = (a -. c, b -. d) let ( *: ) k (a, b) = (k *. a, k *. b) let dot (a, b) (c, d) = (a *. c) +. (b *. d) let norm v = sqrt (dot v v) let unit v = (1. /. norm v) *: v let left (a, b) = (-.b, a) let right (a, b) = (b, -.a) let angle (a, b) = atan2 b a

Most Celtic panels are drawn on a square grid:

(* The square grid of [w] by [h] squares. *) let square_grid w h = let id i j = (j * (w + 1)) + i in let pos = Array.init ((w + 1) * (h + 1)) (fun k -> (float (k mod (w + 1)), float (k / (w + 1)))) in let edges = ref [] in for j = 0 to h do for i = 0 to w do if i < w then edges := (id i j, id (i + 1) j) :: !edges; if j < h then edges := (id i j, id i (j + 1)) :: !edges done done; { pos; edges = Array.of_list (List.rev !edges) } (* Graphs print as their size. *) let pp_graph ppf g = Format.fprintf ppf "<%d points, %d edges>" (Array.length g.pos) (Array.length g.edges);; #install_printer pp_graph

Following the threads

Around the middle of an edge there are four corners: at each end of the edge, the corner on one side of it and the corner on the other. Four pieces of thread leave the middle, one into each corner. A thread goes round its corner to the middle of the next edge about that point, then through that middle, round another corner, and so on until it gets back to where it started.

So we need two moves. corner takes a thread round a point to the next edge. For that, each point must know its edges in order round it, anticlockwise, which around works out by sorting them by angle. through takes a thread through the middle of an edge. The three kinds of junction differ only in which corner they send the thread on to.

(* Around each point, its edges in anticlockwise order, each as the edge and which of its ends (0 or 1) is at this point. *) let around g = let ends = Array.make (Array.length g.pos) [] in Array.iteri (fun e (u, v) -> ends.(u) <- (e, 0) :: ends.(u); ends.(v) <- (e, 1) :: ends.(v)) g.edges; let direction w (e, end_) = let u, v = g.edges.(e) in angle (g.pos.(if end_ = 0 then v else u) -: g.pos.(w)) in Array.mapi (fun w es -> Array.of_list (List.sort (fun a b -> compare (direction w a) (direction w b)) es)) ends (* Four threads meet at the middle of an edge, one heading into each of the four corners beside it. A port names one: the edge, the end it heads towards, and whether the corner is anticlockwise of the edge there, or clockwise. *) type port = { e : int; end_ : int; ccw : bool } let vertex g p = if p.end_ = 0 then fst g.edges.(p.e) else snd g.edges.(p.e) (* Round a corner: to the next edge anticlockwise (or clockwise) about the point, arriving on the side of it that faces back. *) let corner g rot p = let es = rot.(vertex g p) in let n = Array.length es in let rec find i = if es.(i) = (p.e, p.end_) then i else find (i + 1) in let i = find 0 in let e, end_ = es.((if p.ccw then i + 1 else i - 1 + n) mod n) in { e; end_; ccw = not p.ccw } (* Through the middle of an edge. Crossing, a thread carries on to the far end, still on the same turn. A wall along the edge sends it to the far end on its own side; a wall across sends it back to its own end, round the other side. *) let through kind p = match kind with | Cross -> { p with end_ = 1 - p.end_ } | Along -> { p with end_ = 1 - p.end_; ccw = not p.ccw } | Across -> { p with ccw = not p.ccw }

Following one thread marks the ports it uses. Starting again from any unused port finds the next thread, until every port is used.

(* Follow every thread: through an edge's middle, round a corner, through the next middle, until it is back where it started. A thread is the list of middles it passes, each as the port it arrives by and the port it leaves by. *) let threads g kinds = let rot = around g in let index p = (p.e * 4) + (p.end_ * 2) + if p.ccw then 1 else 0 in let seen = Array.make (4 * Array.length g.edges) false in let rec follow start p acc = let q = through kinds.(p.e) p in seen.(index p) <- true; seen.(index q) <- true; let r = corner g rot q in if r = start then List.rev ((p, q) :: acc) else follow start r ((p, q) :: acc) in List.filter_map (fun k -> if seen.(k) then None else let p = { e = k / 4; end_ = k / 2 mod 2; ccw = k mod 2 = 1 } in Some (follow p p [])) (List.init (Array.length seen) Fun.id)

How many separate threads does a 4 by 3 plait have?

let plait = square_grid 4 3;; List.length (threads plait (every Cross plait))

Just one. A single thread, woven through the whole panel with no loose ends, is what the Celtic artists aimed for.

Over, under

Which thread goes over at a crossing? Real interlace alternates: follow any thread and it goes over, then under, then over, all the way round. It might seem that we'd have to search for a way of choosing that works everywhere. In fact one local rule is enough. At a crossing, the thread joining the two anticlockwise corners goes over.

(* At a crossing, the thread from anticlockwise corner to anticlockwise corner goes over. *) let over (p, _) = p.ccw (* Does each thread go over, under, over, under, all the way round? *) let alternates g kinds = let rec ok = function a :: (b :: _ as rest) -> a <> b && ok rest | _ -> true in List.for_all (fun t -> match List.filter_map (fun ((p, _) as j) -> if kinds.(p.e) = Cross then Some (over j) else None) t with | [] -> true | first :: _ as l -> ok (l @ [ first ])) (threads g kinds)

This works because rounding a corner always swaps anticlockwise for clockwise, while going through a crossing keeps it. So a thread arrives at crossing after crossing on alternate sides. A wall swaps sides once going through and once more rounding the next corner, so the next crossing comes out right as well.

alternates plait (every Cross plait);; alternates (square_grid 7 5) (every Cross (square_grid 7 5))
The drawing: where the threads go, and their curves

The only geometry is at the middles and in the corners. A thread leaves the middle of an edge at an angle to it, 45 degrees on a square grid. It rounds each corner the way the old draughtsmen did, with a straight run, an arc of a circle, and another straight run. The circle has to touch both straight lines. Of all the circles that do, round chooses how big, from a sharp corner (0) to the largest that fits (1). Out of each crossing, a thread runs straight for a little way, as it does in drawn knotwork.

(* Where the threads go. [mid] is an edge's middle, [half] half its length. *) let mid g e = let u, v = g.edges.(e) in 0.5 *: (g.pos.(u) +: g.pos.(v)) let half g e = let u, v = g.edges.(e) in 0.5 *. norm (g.pos.(v) -: g.pos.(u)) (* The angle of the corner that the port [p] heads into, anticlockwise from one edge to the other: a whole turn at the end of a lone edge. *) let corner_angle g rot p = let q = corner g rot p in let c = g.pos.(vertex g p) in let d p = mid g p.e -: c in let first, last = if p.ccw then (p, q) else (q, p) in let th = angle (d last) -. angle (d first) in if th <= 1e-9 then th +. (2. *. Float.pi) else th (* How far off its edge a thread leaves the middle: the angle that takes it straight across its corner, averaged with the one on the far side of the crossing, so that it goes straight through. Corners of half a turn or more have no straight way across and do not count. On a square grid it is 45 degrees. *) let slant g rot p = let straight p = let th = corner_angle g rot p in if th < Float.pi -. 0.01 then Some ((Float.pi -. th) /. 2.) else None in match (straight p, straight { p with end_ = 1 - p.end_ }) with | Some a, Some b -> (a +. b) /. 2. | Some a, None | None, Some a -> a | None, None -> Float.pi /. 4. (* The way a thread leaves an edge's middle through the port [p]. *) let heading g rot p = let a = unit (g.pos.(vertex g p) -: mid g p.e) and s = slant g rot p in (cos s *: a) +: (sin s *: if p.ccw then right a else left a) (* A thread passing a middle, from [p] to [q]: a point, and the way it goes. Crossing, it goes over the middle itself; turned back by a wall, it passes a little way off it, on its own side: on a square grid, a quarter of an edge off, so that a thread passing wall after wall runs straight past them. *) let waypoint g rot (p, q) = let hp = heading g rot p and hq = heading g rot q in let at = if p.ccw = q.ccw then mid g p.e else mid g p.e +: ((0.3536 *. half g p.e) *: (hp +: hq)) in (at, unit (hq -: hp)) (* Round each corner as the old draughtsmen did: straight, then an arc of a circle, then straight again. Everything is drawn as cubics; a line is a cubic with its handles on it, and an arc is cut into quarter turns, each close to a cubic. *) type cubic = (float * float) * (float * float) * (float * float) * (float * float) let line a b : cubic = (a, a +: ((1. /. 3.) *: (b -: a)), a +: ((2. /. 3.) *: (b -: a)), b) let cross (a, b) (c, d) = (a *. d) -. They must be at least [s_min] and [u_min], for the straight runs out of crossings. Rounding a corner anticlockwise about its point (when the corner is on the anticlockwise side of the edge it leaves), a thread turns about as much as the corner is wide, less the slants. *) let turning ta tb estimate = let exact = atan2 (cross ta tb) (dot ta tb) in exact +. Float.abs turn *. Last, draw puts it together as SVG, a string, and show puts that on the page in a display of its own, with X_ocaml_lib.html. There is no need to cut the threads where they go under. Each thread is drawn whole, as one thick line, in any order. Then at every crossing, a short piece of the thread that goes over is drawn again, on top of a slightly thicker line in the colour of the background. That rubs out the thread beneath and leaves a gap on either side of the one above. With ~outline, each thread gets dark edges too, and with ~construction, the graph is drawn underneath.

(w *. scale)) (String.concat "" ((el "rect" [ ("x", num x0); ("y", num y0); ("width", num w); ("height", num h); ("fill", vellum) ] :: (if construction then edges k else [])) @ threads @ over_crossings k @ (if construction then walls_and_points k else []) @ targets)) (* The threads, and their corners. *) let prepare ?round ~width ~outline ~colours g kinds = let rot = around g in let ts = threads g kinds in let cs = List.map (corners ?round ~straight:(0.9 *. width) g rot kinds) ts in { g; rot; kinds; width; outline; colours; ts; cs } (* [draw]'s work, with its options as options. *) let picture ~width ~round ~outline ~colours ~construction ~on_edge ~scale g kinds = (* Ribbons a third as wide as the shortest edge, unless told. *) let width = match width with Some w -> w | None -> 0.34 *. shortest g in let no = Option.value ~default:false in let k = prepare ?round ~width ~outline:(no outline) ~colours:(no colours) g kinds in svg k ~scale:(Option.value scale ~default:56. /. shortest g) ~construction:(no construction) ?on_edge () let draw ?width ?round ?outline ?colours ?construction ?on_edge ?scale g kinds = picture ~width ~round ~outline ~colours ~construction ~on_edge ~scale g kinds (* A picture in a display of its own, under the cell. *) let show picture = ignore (X_ocaml_lib.html picture) let () = show (draw ~construction:true plait (every Cross plait))

The pictures from here on have controls. They are HTML as well: a slider or a checkbox whose data-callback attribute holds a callback token, from X_ocaml_lib.callback, calls the OCaml function behind it as the reader moves it, with its value. The function sets what the control stands for and redraws the picture, which is X_ocaml_lib.update with the new SVG. The controls go in a display of their own, which is never replaced, so a slider stays in the reader's hand while the picture beside it changes.

(* Controls, as HTML. Each is given [redraw], and calls back through the token in its data-callback attribute: an input with its value as the reader moves it, a button when it is pressed. [redraw], if given, is set to the function that redraws it, for other callbacks to call. *) let interact ?title ?(redraw = ref ignore) picture controls = let shown = X_ocaml_lib.html (picture ()) in redraw := (fun () -> X_ocaml_lib.update shown (picture ())); let head = match title with None -> "" | Some t -> Printf.sprintf "<h3>%s</h3>" t in let panel = String.concat "" (List.map (fun c -> c !redraw) controls) in ignore (X_ocaml_lib.html (Printf.sprintf {|<div class="panel">%s%s</div>|} head panel)) let caption ?badge text = let pill = match badge with None -> "" | Some kind -> Printf.sprintf {| class="badge %s"|} kind in Printf.sprintf {|<p class="caption"><span%s>%s</span></p>|} pill text let plural n thing = Printf.sprintf "%d %s%s" n thing (if n = 1 then "" else "s")

Plaits

With no breaks, a square grid gives a plait. The threads run diagonally and turn back at the border. Change the size and watch how many threads there are, try roundness to see how the turns are made, and dark edges for the look of a manuscript.

(* What the controls set. *) let across = ref 5 and down = ref 3 and colours = ref true and outline = ref false let construction = ref false and round = ref 0.7 let plait () = let g = square_grid !across !down in let n = List.length (threads g (every Cross g)) in draw ~round:!round ~outline:!outline ~colours:!colours ~construction:!construction g (every Cross g) ^ caption (Printf.sprintf "%d by %d squares: %s." !across !down (plural n "thread")) let () = interact plait [ int_slider "across" ~min:1 ~max:12 across; int_slider "down" ~min:1 ~max:12 down; checkbox "a colour for each thread" colours; checkbox "dark edges" outline; checkbox "show the grid" construction; float_slider "roundness" ~min:0. ~max:1. ~step:0.05 round ]

Some sizes give one thread and others give many: a 5 by 3 plait has two, and a 5 by 5 has six. Can you see the rule before reading on?

A plait w squares across and h down has gcd(w + 1, h + 1) threads. Here is a check of every size up to 12 by 12:

Breaks

A plait is regular, and knotwork is made by breaking it. Click an edge of the grid to turn its crossing into a wall along the edge, click again for a wall across it, and a third time to make it a crossing again. With the mirrors on, each click also changes the edges it reflects to, which is how Celtic panels get their symmetry.

The editor's workings: edges by name, mirrors, and breaks at random (* The breaks on a grid, kept apart from its size: each edge is known by its middle, doubled to make whole numbers, and only the edges that are not crossings are written down. *) module Key = Map.Make (struct type t = int * int let compare = compare end) let key g e = let x, y = mid g e in (Float.to_int (Float.round (2. *. x)), Float.to_int (Float.round (2. *. y))) let kinds_of g breaks = Array.init (Array.length g.edges) (fun e -> Option.value ~default:Cross (Key.find_opt (key g e) breaks)) let next = function Cross -> Along | Along -> Across | Across -> Cross let cols = ref 8 let rows = ref 6 let breaks = ref Key.empty let mirror_x = ref true let mirror_y = ref true (* The edges that the mirrors turned on send the edge at [(x, y)] to. *) let orbit (x, y) = let w = 2 * !cols and h = 2 * !rows in let xs = if !mirror_x then [ x; w - x ] else [ x ] in let ys = if !mirror_y then [ y; h - y ] else [ y ] in List.sort_uniq compare (List.concat_map (fun x -> List.map (fun y -> (x, y)) ys) xs) let set ks kind m = List.fold_left (fun m k -> if kind = Cross then Key.remove k m else Key.add k kind m) m ks let click g e = let k = key g e in let now = Option.value ~default:Cross (Key.find_opt k !breaks) in breaks := set (orbit k) (next now) !breaks (* Breaks at random, the same in every mirror. An edge on the border gets no wall along it, which would only box the knot in. *) let scatter ~density g = let w = 2 * !cols and h = 2 * !rows in let border (x, y) = x = 0 || y = 0 || x = w || y = h in Array.fold_left (fun m e -> let k = key g e in let ks = orbit k in if k <> List.hd ks || Random.float 1. >= density then m else set ks (if border k || Random.bool () then Across else Along) m) Key.empty (Array.init (Array.length g.edges) Fun.id) (* Try again until the knot is a single thread, or give up after 400. *) let random ~density ~one () = let g = square_grid !cols !rows in let rec go n = let m = scatter ~density g in if (not one) || n = 0 || List.length (threads g (kinds_of g m)) = 1 then m else go (n - 1) in breaks := go 400
let colours = ref false and construction = ref true let density = ref 0.3 and one_thread = ref true (* An edge clicked, which redraws the knot once it is shown. *) let redraw = ref ignore let clicked = X_ocaml_lib.callback (fun e -> click (square_grid !cols !rows) (int_of_string e); !redraw ()) let knot () = let g = square_grid !cols !rows in let kinds = kinds_of g !breaks in let n = List.length (threads g kinds) in draw ~colours:!colours ~construction:!construction ~on_edge:clicked ~scale:64. g kinds ^ caption ~badge:(if n = 1 then "good" else "info") (plural n "thread") let controls = [ int_slider "across" ~min:1 ~max:14 cols; int_slider "down" ~min:1 ~max:14 rows; checkbox "mirror left and right" mirror_x; checkbox "mirror top and bottom" mirror_y; checkbox "show the grid" construction; checkbox "a colour for each thread" colours; float_slider "random breaks" ~min:0. ~max:0.8 ~step:0.05 density; checkbox "only one thread" one_thread; buttons [ button ~primary:true "random" (fun () -> random ~density:!density ~one:!one_thread ()); button "clear" (fun () -> breaks := Key.empty) ] ] let () = interact ~title:"Breaks" ~redraw knot controls

Press random to scatter breaks at random, symmetrically. With only one thread checked, it keeps trying until the whole panel is one unbroken thread. Show the colours to see how breaks join threads together and split them apart.

Beyond the grid

Nothing in the method needs a square grid: any graph drawn in the plane gives a knot. A triangle's three edges give three crossings, and one thread through them: the triquetra, or trefoil knot.

(* Other graphs. [polygon n] is a ring of [n] points; [wheel n] adds a hub with a spoke to each; [triangles n] is a triangle cut into triangles, [n] to a side. *) let ring n r = Array.init n (fun i -> let a = (2. *. Float.pi *. float i /. float n) -. (Float.pi /. 2.) in (r *. cos a, r *. sin a)) let polygon n = { pos = ring n (0.7 /. sin (Float.pi /. float n)); edges = Array.init n (fun i -> (i, (i + 1) mod n)) } let wheel n = let r = Float.max 1.5 (0.7 /. sin (Float.pi /. float n)) in { pos = Array.append [| (0., 0.) |] (ring n r); edges = Array.concat [ Array.init n (fun i -> (0, i + 1)); Array.init n (fun i -> (i + 1, ((i + 1) mod n) + 1)) ] } let triangles n = let pts = List.concat (List.init (n + 1) (fun j -> List.init (n + 1 - j) (fun i -> (i, j)))) in let id = Hashtbl.create 16 in List.iteri (fun k p -> Hashtbl.add id p k) pts; let pos = Array.of_list (List.map (fun (i, j) -> (float i +. (0.5 *. float j), -.(sqrt 3. /. 2.) *. float j)) pts) in let edges = List.concat_map (fun (i, j) -> if i + j + 1 > n then [] else [ (Hashtbl.find id (i, j), Hashtbl.find id (i + 1, j)); (Hashtbl.find id (i, j), Hashtbl.find id (i, j + 1)); (Hashtbl.find id (i + 1, j), Hashtbl.find id (i, j + 1)) ]) pts in { pos; edges = Array.of_list edges } let triangle = polygon 3 let () = show (draw ~construction:true triangle (every Cross triangle))

Put a point in the middle of the triangle and join it to the corners. That is the graph of a tetrahedron, and its knot is the Borromean rings: three loops, no two of them linked, which still can't be pulled apart.

let k4 = wheel 3 let () = show (draw ~colours:true ~construction:true ~width:0.3 k4 (every Cross k4))

A ring of n points gives two threads twisted round each other n times, which make one thread when n is odd. A wheel is a ring with spokes, and a triangle can be cut into smaller triangles, like a square into a grid.

Knot theorists use the same construction in reverse. An alternating knot diagram gives a graph drawn in the plane, its Tait graph, and the knot is drawn back from the graph exactly as on this page.
