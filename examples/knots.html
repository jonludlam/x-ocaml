Celtic knots

Drawn by following a thread around a graph.

The interlace in the Book of Kells and on the high crosses looks as if it must have been drawn one careful stroke at a time. It was built from a method, though, and the method is simple enough to put into a program. Start with a regular plait, where every strand goes over, then under, then over. Then break it here and there, turning strands back where they would have crossed. J. Romilly Allen described knotwork this way in 1904, and George Bain's Celtic Art: The Methods of Construction (1951) taught a generation to draw it.

This page takes a slightly more general view, following Christian Mercat. Every Celtic knot is drawn over a graph: dots, with lines between them. The threads cross at the middle of every line and wrap round the dots. A plait is the knot of a square grid, and breaks are changes to single edges. The cells below are OCaml, running in your browser. They build the graph, follow the threads and draw the picture, and you can change any of them and run it again.

The graph

A graph here is a set of points in the plane, joined by straight edges. At the middle of each edge, one of three things happens.

Cross
the two threads that meet there cross over each other;
Along
there is a wall along the edge, and the threads turn back to stay on their own side of it;
Across
there is a wall across the edge, and the threads turn back to stay at their own end of it.
(* A graph drawn in the plane: points, and straight edges between them. The threads of the knot cross at the middle of every edge. *) type graph = { pos : (float * float) array; edges : (int * int) array } (* At each edge the threads cross, or turn back before it: [Along] puts a wall along the edge, [Across] puts one across it. *) type junction = Cross | Along | Across let every kind g = Array.make (Array.length g.edges) kind (* Points in the plane are pairs of floats. *) let ( +: ) (a, b) (c, d) = (a +. c, b +. d) let ( -: ) (a, b) (c, d) = (a -. c, b -. d) let ( *: ) k (a, b) = (k *. a, k *. b) let dot (a, b) (c, d) = (a *. c) +. (b *. d) let norm v = sqrt (dot v v) let unit v = (1. /. norm v) *: v let left (a, b) = (-.b, a) let right (a, b) = (b, -.a) let angle (a, b) = atan2 b a

Most Celtic panels are drawn on a square grid:

(* The square grid of [w] by [h] squares. *) let square_grid w h = let id i j = (j * (w + 1)) + i in let pos = Array.init ((w + 1) * (h + 1)) (fun k -> (float (k mod (w + 1)), float (k / (w + 1)))) in let edges = ref [] in for j = 0 to h do for i = 0 to w do if i < w then edges := (id i j, id (i + 1) j) :: !edges; if j < h then edges := (id i j, id i (j + 1)) :: !edges done done; { pos; edges = Array.of_list (List.rev !edges) } (* Graphs print as their size. *) let pp_graph ppf g = Format.fprintf ppf "<%d points, %d edges>" (Array.length g.pos) (Array.length g.edges);; #install_printer pp_graph

Following the threads

Around the middle of an edge there are four corners: at each end of the edge, the corner on one side of it and the corner on the other. Four pieces of thread leave the middle, one into each corner. A thread goes round its corner to the middle of the next edge about that point, then through that middle, round another corner, and so on until it gets back to where it started.

So we need two moves. corner takes a thread round a point to the next edge. For that, each point must know its edges in order round it, anticlockwise, which around works out by sorting them by angle. through takes a thread through the middle of an edge. The three kinds of junction differ only in which corner they send the thread on to.

(* Around each point, its edges in anticlockwise order, each as the edge and which of its ends (0 or 1) is at this point. *) let around g = let ends = Array.make (Array.length g.pos) [] in Array.iteri (fun e (u, v) -> ends.(u) <- (e, 0) :: ends.(u); ends.(v) <- (e, 1) :: ends.(v)) g.edges; let direction w (e, end_) = let u, v = g.edges.(e) in angle (g.pos.(if end_ = 0 then v else u) -: g.pos.(w)) in Array.mapi (fun w es -> Array.of_list (List.sort (fun a b -> compare (direction w a) (direction w b)) es)) ends (* Four threads meet at the middle of an edge, one heading into each of the four corners beside it. A port names one: the edge, the end it heads towards, and whether the corner is anticlockwise of the edge there, or clockwise. *) type port = { e : int; end_ : int; ccw : bool } let vertex g p = if p.end_ = 0 then fst g.edges.(p.e) else snd g.edges.(p.e) (* Round a corner: to the next edge anticlockwise (or clockwise) about the point, arriving on the side of it that faces back. *) let corner g rot p = let es = rot.(vertex g p) in let n = Array.length es in let rec find i = if es.(i) = (p.e, p.end_) then i else find (i + 1) in let i = find 0 in let e, end_ = es.((if p.ccw then i + 1 else i - 1 + n) mod n) in { e; end_; ccw = not p.ccw } (* Through the middle of an edge. Crossing, a thread carries on to the far end, still on the same turn. A wall along the edge sends it to the far end on its own side; a wall across sends it back to its own end, round the other side. *) let through kind p = match kind with | Cross -> { p with end_ = 1 - p.end_ } | Along -> { p with end_ = 1 - p.end_; ccw = not p.ccw } | Across -> { p with ccw = not p.ccw }

Following one thread marks the ports it uses. Starting again from any unused port finds the next thread, until every port is used.

(* Follow every thread: through an edge's middle, round a corner, through the next middle, until it is back where it started. A thread is the list of middles it passes, each as the port it arrives by and the port it leaves by. *) let threads g kinds = let rot = around g in let index p = (p.e * 4) + (p.end_ * 2) + if p.ccw then 1 else 0 in let seen = Array.make (4 * Array.length g.edges) false in let rec follow start p acc = let q = through kinds.(p.e) p in seen.(index p) <- true; seen.(index q) <- true; let r = corner g rot q in if r = start then List.rev ((p, q) :: acc) else follow start r ((p, q) :: acc) in List.filter_map (fun k -> if seen.(k) then None else let p = { e = k / 4; end_ = k / 2 mod 2; ccw = k mod 2 = 1 } in Some (follow p p [])) (List.init (Array.length seen) Fun.id)

How many separate threads does a 4 by 3 plait have?

let plait = square_grid 4 3;; List.length (threads plait (every Cross plait))

Just one. A single thread, woven through the whole panel with no loose ends, is what the Celtic artists aimed for.

Over, under

Which thread goes over at a crossing? Real interlace alternates: follow any thread and it goes over, then under, then over, all the way round. It might seem that we'd have to search for a way of choosing that works everywhere. In fact one local rule is enough. At a crossing, the thread joining the two anticlockwise corners goes over.

(* At a crossing, the thread from anticlockwise corner to anticlockwise corner goes over. *) let over (p, _) = p.ccw (* Does each thread go over, under, over, under, all the way round? *) let alternates g kinds = let rec ok = function a :: (b :: _ as rest) -> a <> b && ok rest | _ -> true in List.for_all (fun t -> match List.filter_map (fun ((p, _) as j) -> if kinds.(p.e) = Cross then Some (over j) else None) t with | [] -> true | first :: _ as l -> ok (l @ [ first ])) (threads g kinds)

This works because rounding a corner always swaps anticlockwise for clockwise, while going through a crossing keeps it. So a thread arrives at crossing after crossing on alternate sides. A wall swaps sides once going through and once more rounding the next corner, so the next crossing comes out right as well.

alternates plait (every Cross plait);; alternates (square_grid 7 5) (every Cross (square_grid 7 5))
The drawing: where the threads go, curves and ribbons

The only geometry is at the middles and in the corners. A thread leaves the middle of an edge at an angle to it, 45 degrees on a square grid. It rounds each corner the way the old draughtsmen did, with a straight run, an arc of a circle, and another straight run. The circle has to touch both straight lines. Of all the circles that do, round chooses how big, from a sharp corner (0) to the largest that fits (1). Where the thread goes under another, it stops a little short on each side, always on a straight run.

(* Where the threads go. [mid] is an edge's middle, [half] half its length. *) let mid g e = let u, v = g.edges.(e) in 0.5 *: (g.pos.(u) +: g.pos.(v)) let half g e = let u, v = g.edges.(e) in 0.5 *. norm (g.pos.(v) -: g.pos.(u)) (* The angle of the corner that the port [p] heads into, anticlockwise from one edge to the other: a whole turn at the end of a lone edge. *) let corner_angle g rot p = let q = corner g rot p in let c = g.pos.(vertex g p) in let d p = mid g p.e -: c in let first, last = if p.ccw then (p, q) else (q, p) in let th = angle (d last) -. angle (d first) in if th <= 1e-9 then th +. (2. *. Float.pi) else th (* How far off its edge a thread leaves the middle: the angle that takes it straight across its corner, averaged with the one on the far side of the crossing, so that it goes straight through. Corners of half a turn or more have no straight way across and do not count. On a square grid it is 45 degrees. *) let slant g rot p = let straight p = let th = corner_angle g rot p in if th < Float.pi -. 0.01 then Some ((Float.pi -. th) /. 2.) else None in match (straight p, straight { p with end_ = 1 - p.end_ }) with | Some a, Some b -> (a +. b) /. 2. | Some a, None | None, Some a -> a | None, None -> Float.pi /. 4. (* The way a thread leaves an edge's middle through the port [p]. *) let heading g rot p = let a = unit (g.pos.(vertex g p) -: mid g p.e) and s = slant g rot p in (cos s *: a) +: (sin s *: if p.ccw then right a else left a) (* A thread passing a middle, from [p] to [q]: a point, and the way it goes. Crossing, it goes over the middle itself; turned back by a wall, it passes a little way off it, on its own side: on a square grid, a quarter of an edge off, so that a thread passing wall after wall runs straight past them. *) let waypoint g rot (p, q) = let hp = heading g rot p and hq = heading g rot q in let at = if p.ccw = q.ccw then mid g p.e else mid g p.e +: ((0.3536 *. half g p.e) *: (hp +: hq)) in (at, unit (hq -: hp)) (* Round each corner as the old draughtsmen did: straight, then an arc of a circle, then straight again. Everything is drawn as cubics; a line is a cubic with its handles on it, and an arc is cut into quarter turns, each close to a cubic. *) type cubic = (float * float) * (float * float) * (float * float) * (float * float) let line a b : cubic = (a, a +: ((1. /. 3.) *: (b -: a)), a +: ((2. /. 3.) *: (b -: a)), b) let cross (a, b) (c, d) = (a *. d) -. (b *. c) (* The arc about [c] of radius [r], from angle [a0], turning [sweep] (anticlockwise if positive). *) let arc c r a0 sweep = let n = max 1 (Float.to_int (Float.ceil (Float.abs sweep /. (Float.pi /. 2.) -. 1e-6))) in let d = sweep /. float n in let k = 4. /. 3. *. tan (d /. 4.) *. r in let at a = c +: (r *: (cos a, sin a)) and tangent a = (-.sin a, cos a) in List.init n (fun i -> let a = a0 +. (d *. float i) and b = a0 +. (d *. float (i + 1)) in ((at a, at a +: (k *: tangent a), at b -: (k *: tangent b), at b) : cubic)) (* From [a] heading [ta] to [b] heading [tb], turning through [turn] (anticlockwise if positive): go straight a distance [s], round a circle of radius [r], and straight a distance [u] into [b]. The centre is [r] to the turning side of both lines, so s ta + u tb = (b - a) + r (n2 - n1) and [s] and [u] grow or shrink steadily with [r]. They must be at least [s_min] and [u_min], so that a ribbon cut short near a crossing is cut on a straight. Turning less than half a turn, the circles that fit run from nothing up to one that leaves the least straight at one end, and [round] is how far along to go; turning more, the smallest circle that fits is taken. *) let fillet ~round ?(s_min = 0.) ?(u_min = 0.) (a, ta) (b, tb) turn = let side v = if turn > 0. then left v else right v in let n1 = side ta and n2 = side tb in let det = cross ta tb in let arc_from t1 r = let c = t1 +: (r *: n1) in let t2 = c -: (r *: n2) in (line a t1 :: arc c r (angle (t1 -: c)) turn) @ [ line t2 b ] in if Float.abs det < 0.02 then if dot ta tb > 0. then None else (* A U-turn between parallel lines: the circle has to fit between them, and only the difference of the straights is fixed. *) let r = Float.abs (dot (b -: a) n1) /. 2. in let along = dot (b -: a) ta in Some (arc_from (a +: (Float.max s_min (along +. u_min) *: ta)) r) else let solve d = (cross d tb /. det, cross ta d /. det) in let s0, u0 = solve (b -: a) and s1, u1 = solve (n2 -: n1) in (* The radii that leave both straights at least zero long. *) let lo = ref 0. and hi = ref infinity in List.iter (fun (x0, x1) -> if x1 > 1e-9 then lo := Float.max !lo (-.x0 /. x1) else if x1 < -1e-9 then hi := Float.min !hi (-.x0 /. x1) else if x0 < -1e-9 then hi := -1.) (3. *. (cos (Float.min 3. (Float.abs turn) /. 4.) ** 2.)) in let k = if Float.abs turn > Float.pi /. 2. then Float.max k reach else k in [ (a, a +: (k *: ta), b -: (k *: tb), b) ]) (* A thread as its corners, each a list of cubics, and whether it starts, or ends, going under a crossing. *) type piece = { curves : cubic list; from_under : bool; to_under : bool } let under kinds ((p, _) as j) = kinds.(p.e) = Cross && not (over j) (* How far a thread turns rounding a corner: the angle between the ways it leaves and arrives, plus as many whole turns as it takes to be nearest [estimate]. Rounding a corner anticlockwise about its point (when the corner is on the anticlockwise side of the edge it leaves), a thread turns about as much as the corner is wide, less the slants. *) let turning ta tb estimate = let exact = atan2 (cross ta tb) (dot ta tb) in exact +. Float.pi))) let pieces ?(round = 0.7) ?(straight = 0.) g rot kinds thread = let js = Array.of_list thread in let n = Array.length js in List.init n (fun i -> let ((_, q) as j) = js.(i) and ((r, _) as j') = js.((i + 1) mod n) in let estimate = corner_angle g rot q +. slant g rot q +. slant g rot r -. Float.pi in let ((_, ta) as from) = waypoint g rot j and ((_, tb) as to_) = waypoint g rot j' in let turn = turning ta tb (if q.ccw then estimate else -.estimate) in let reach = 0.6 *. from_under = under kinds j; to_under = under kinds j' }) (* Cut the threads into ribbons, stopping [gap] short of each crossing they go under. *) let point_on ((p0, p1, p2, p3) : cubic) t = let s = 1. -. t in ((s *. s *. s) *: p0) +: ((3. *. s *. s *. t) *: p1) +: ((3. *. s *. t *. t) *: p2) +: ((t *. t *. t) *: p3) let length c = let pts = List.init 13 (fun i -> point_on c (float i /. 12.)) in fst (List.fold_left (fun (l, p) q -> (l +. norm (q -: p), q)) (0., List.hd pts) (List.tl pts)) (* The two halves of a cubic, split at [t]: de Casteljau. *) let split ((p0, p1, p2, p3) : cubic) t : cubic * cubic = let mix a b = a +: (t *: (b -: a)) in let a = mix p0 p1 and b = mix p1 p2 and c = mix p2 p3 in let d = mix a b and e = mix b c in let m = mix d e in ((p0, a, d, m), (m, e, c, p3)) (* Drop the first [d] of a list of cubics, or with [rev] the last. *) let reverse ((p0, p1, p2, p3) : cubic) : cubic = (p3, p2, p1, p0) let rec drop d = function | c :: rest when d > 0. -> let l = length c in if d >= l && rest <> [] then drop (d -. l) rest else snd (split c (Float.min 0.99 (d /. l))) :: rest | cs -> cs let trim ~gap pc = let total = List.fold_left (fun l c -> l +. length c) 0. pc.curves in let gap = Float.min gap (0.45 *. total) in let cs = if pc.from_under then drop gap pc.curves else pc.curves in if pc.to_under then List.rev_map reverse (drop gap (List.rev_map reverse cs)) else cs (* A thread's ribbons, from one gap to the next; a thread that never goes under is one closed loop. *) let ribbons pcs = if not (List.exists (fun pc -> pc.from_under) pcs) then [ (true, pcs) ] else let rec start = function pc :: rest when not pc.from_under -> start (rest @ [ pc ]) | l -> l in let rec cut acc cur = function | [] -> List.rev (List.rev cur :: acc) | pc :: rest when pc.from_under && cur <> [] -> cut (List.rev cur :: acc) [ pc ] rest | pc :: rest -> cut acc (pc :: cur) rest in List.map (fun r -> (false, r)) (cut [] [] (start pcs)) let pt (x, y) = Printf.sprintf "%.3f,%.3f" x y let path ~gap (closed, pcs) = let cs = List.concat_map (trim ~gap) pcs in let p0, _, _, _ = List.hd cs in String.concat "" (("M" ^ pt p0) :: List.map (fun (_, a, b, c) -> Printf.sprintf "C%s %s %s" (pt a) (pt b) (pt c)) cs @ [ (if closed then "Z" else "") ])

Plaits

With no breaks, a square grid gives a plait. The threads run diagonally and turn back at the border. Change the size and watch how many threads there are, and try roundness to see how the turns are made.

Breaks

A plait is regular, and knotwork is made by breaking it. Click an edge of the grid to turn its crossing into a wall along the edge, click again for a wall across it, and a third time to make it a crossing again. With the mirrors on, each click also changes the edges it reflects to, which is how Celtic panels get their symmetry.

The editor's workings: edges by name, mirrors, and breaks at random (* The breaks on a grid, kept apart from its size: each edge is known by its middle, doubled to make whole numbers, and only the edges that are not crossings are written down. *) module Key = Map.Make (struct type t = int * int let compare = compare end) let key g e = let x, y = mid g e in (Float.to_int (Float.round (2. *. x)), Float.to_int (Float.round (2. *. y))) let kinds_of g breaks = Array.init (Array.length g.edges) (fun e -> Option.value ~default:Cross (Key.find_opt (key g e) breaks)) let next = function Cross -> Along | Along -> Across | Across -> Cross let cols = Ui.Var.create 8 let rows = Ui.Var.create 6 let breaks = Ui.Var.create Key.empty let mirror_x = Ui.Var.create true let mirror_y = Ui.Var.create true (* The edges that the mirrors turned on send the edge at [(x, y)] to. *) let orbit (x, y) = let w = 2 * Ui.Var.peek cols and h = 2 * Ui.Var.peek rows in let xs = if Ui.Var.peek mirror_x then [ x; w - x ] else [ x ] in let ys = if Ui.Var.peek mirror_y then [ y; h - y ] else [ y ] in List.sort_uniq compare (List.concat_map (fun x -> List.map (fun y -> (x, y)) ys) xs) let set ks kind m = List.fold_left (fun m k -> if kind = Cross then Key.remove k m else Key.add k kind m) m ks let click g e = let k = key g e in let now = Option.value ~default:Cross (Key.find_opt k (Ui.Var.peek breaks)) in Ui.Var.update breaks (set (orbit k) (next now)) (* Breaks at random, the same in every mirror. An edge on the border gets no wall along it, which would only box the knot in. *) let scatter ~density g = let w = 2 * Ui.Var.peek cols and h = 2 * Ui.Var.peek rows in let border (x, y) = x = 0 || y = 0 || x = w || y = h in Array.fold_left (fun m e -> let k = key g e in let ks = orbit k in if k <> List.hd ks || Random.float 1. >= density then m else set ks (if border k || Random.bool () then Across else Along) m) Key.empty (Array.init (Array.length g.edges) Fun.id) (* Try again until the knot is a single thread, or give up after 400. *) let random ~density ~one () = let g = square_grid (Ui.Var.peek cols) (Ui.Var.peek rows) in let rec go n = let m = scatter ~density g in if (not one) || n = 0 || List.length (threads g (kinds_of g m)) = 1 then m else go (n - 1) in Ui.Var.set breaks (go 400)
let () = let open Ui in let colours = Var.create false and construction = Var.create true in let density = Var.create 0.3 and one = Var.create true in let knot () = let g = square_grid (Var.get cols) (Var.get rows) in draw ~colours:(Var.get colours) ~construction:(Var.get construction) ~on_edge:(click g) ~scale:64. g (kinds_of g (Var.get breaks)) in let count () = let g = square_grid (Var.get cols) (Var.get rows) in let n = List.length (threads g (kinds_of g (Var.get breaks))) in badge ~kind:(if n = 1 then "good" else "info") (Printf.sprintf "%d thread%s" n (if n = 1 then "" else "s")) in show (hbox ~align:"flex-start" [ styled [ ("flex", "1 1 24rem"); ("min-width", "0") ] (dyn knot); styled [ ("flex", "0 1 15rem") ] (card ~title:"Breaks" [ dyn count; int_slider ~label:"across" ~min:1 ~max:14 cols; int_slider ~label:"down" ~min:1 ~max:14 rows; checkbox ~label:"mirror left and right" mirror_x; checkbox ~label:"mirror top and bottom" mirror_y; checkbox ~label:"show the grid" construction; checkbox ~label:"a colour for each thread" colours; float_slider ~label:"random breaks" ~min:0. ~max:0.8 ~step:0.05 density; checkbox ~label:"only one thread" one; hbox ~gap:"0.4rem" [ button ~kind:"primary" "random" (fun () -> random ~density:(Var.peek density) ~one:(Var.peek one) ()); button "clear" (fun () -> Var.set breaks Key.empty) ] ]) ])

Press random to scatter breaks at random, symmetrically. With only one thread checked, it keeps trying until the whole panel is one unbroken thread. Show the colours to see how breaks join threads together and split them apart.

Beyond the grid

Nothing in the method needs a square grid: any graph drawn in the plane gives a knot. A triangle's three edges give three crossings, and one thread through them: the triquetra, or trefoil knot.

(* Other graphs. [polygon n] is a ring of [n] points; [wheel n] adds a hub with a spoke to each; [triangles n] is a triangle cut into triangles, [n] to a side. *) let ring n r = Array.init n (fun i -> let a = (2. *. Float.pi *. float i /. float n) -. (Float.pi /. 2.) in (r *. cos a, r *. sin a)) let polygon n = { pos = ring n (0.7 /. sin (Float.pi /. float n)); edges = Array.init n (fun i -> (i, (i + 1) mod n)) } let wheel n = let r = Float.max 1.5 (0.7 /. sin (Float.pi /. float n)) in { pos = Array.append [| (0., 0.) |] (ring n r); edges = Array.concat [ Array.init n (fun i -> (0, i + 1)); Array.init n (fun i -> (i + 1, ((i + 1) mod n) + 1)) ] } let triangles n = let pts = List.concat (List.init (n + 1) (fun j -> List.init (n + 1 - j) (fun i -> (i, j)))) in let id = Hashtbl.create 16 in List.iteri (fun k p -> Hashtbl.add id p k) pts; let pos = Array.of_list (List.map (fun (i, j) -> (float i +. (0.5 *. float j), -.(sqrt 3. /. 2.) *. float j)) pts) in let edges = List.concat_map (fun (i, j) -> if i + j + 1 > n then [] else [ (Hashtbl.find id (i, j), Hashtbl.find id (i + 1, j)); (Hashtbl.find id (i, j), Hashtbl.find id (i, j + 1)); (Hashtbl.find id (i + 1, j), Hashtbl.find id (i, j + 1)) ]) pts in { pos; edges = Array.of_list edges } let triangle = polygon 3;; Ui.show (draw ~construction:true triangle (every Cross triangle))

Put a point in the middle of the triangle and join it to the corners. That is the graph of a tetrahedron, and its knot is the Borromean rings: three loops, no two of them linked, which still can't be pulled apart.

let k4 = wheel 3;; Ui.show (draw ~colours:true ~construction:true ~width:0.3 k4 (every Cross k4))

A ring of n points gives two threads twisted round each other n times, which make one thread when n is odd. A wheel is a ring with spokes, and a triangle can be cut into smaller triangles, like a square into a grid.

Knot theorists use the same construction in reverse. An alternating knot diagram gives a graph drawn in the plane, its Tait graph, and the knot is drawn back from the graph exactly as on this page.
